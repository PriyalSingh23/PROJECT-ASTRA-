# Plan 04-02: STAR-V Safety Lockout and Relay Telemetry Monitoring

## Objective
Enforce permanent software safety lockout on the STAR-V tactical SDR adapter preventing unauthorized physical RF transmission, validate ground relay telemetry reporting (battery, temperature, queue size) with store-and-forward threshold failsafes, and verify decoupled flight safety controls on aerial relay payloads.

<must_haves>
- STAR-V adapter enforces `TransportReadiness.LOCKED_OUT` and `TransportConnectionState.OFFLINE`.
- Any transmission attempt via STAR-V returns `success: false`, `error_code: "STARV_SAFETY_LOCKOUT"`, and clear safety lockout details.
- Relay nodes report real-time telemetry: battery percentage, temperature, and storage utilization.
- Relay forwarding automatically halts if battery drops below critical threshold (5%) or storage reaches capacity.
- Simulated aerial relays enforce `flight_failsafe_independent: True`, strictly decoupling payload communications from flight controls.
- Integration tests in `tests/integration/test_adapters.py` and `tests/integration/test_relay_nodes.py` pass.
</must_haves>
