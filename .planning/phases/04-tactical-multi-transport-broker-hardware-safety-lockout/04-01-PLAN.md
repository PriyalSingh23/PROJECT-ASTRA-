# Plan 04-01: Transport Adapter Contracts and DMR 280-Byte Ceiling Validation

## Objective
Enforce unified transport routing rules across the multi-transport broker, ensure `TransportManager` dispatches only to adapters in `READY` or `SIMULATION_ONLY` states, validate Motorola MOTOTRBO TMS adapter enforcement of the strict 280-byte DMR packet ceiling, and verify through automated integration tests.

<must_haves>
- `TransportManager` validates transport readiness before dispatch, filtering out `LOCKED_OUT` and `OFFLINE` adapters.
- Motorola MOTOTRBO adapter accepts payloads $\le 280$ bytes and returns a valid `mot-tms-` delivery ID.
- Motorola MOTOTRBO adapter strictly rejects payloads $> 280$ bytes with `success: false` and `error_code: "PAYLOAD_TOO_LARGE"`.
- Automated tests in `tests/integration/test_adapters.py` (`test_motorola_adapter_capability_and_limits` and `test_transport_manager_routing_decision`) execute cleanly with exit code 0.
</must_haves>
