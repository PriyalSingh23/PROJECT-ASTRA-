# Plan 01-01: Model Column, Serialization, and AckManager Signature Reconciliation

## Objective
Add `signed_ack_receipt` to the SQLAlchemy `Message` model in `messaging/models.py`, ensure `to_dict()` serializes it, update `AckManager.process_ack_at_sender()` to populate `message.signed_ack_receipt` with the verified HMAC receipt upon ACK arrival, and add an automated test asserting receipt reconciliation in `tests/test_offline_messaging.py`.

<must_haves>
- `Message` model in `messaging/models.py` has `signed_ack_receipt = Column(Text, nullable=True)`.
- `Message.to_dict()` serializes `"signed_ack_receipt": self.signed_ack_receipt`.
- `AckManager.process_ack_at_sender()` populates `message.signed_ack_receipt` with the verified receipt string.
- `safe_metadata` in the `ACK_VALIDATED_DELIVERED` event records `signed_receipt`.
- New unit test `test_21_signed_ack_receipt_reconciliation` in `tests/test_offline_messaging.py` passes.
</must_haves>
