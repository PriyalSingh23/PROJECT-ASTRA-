# Plan 02-01: Dual-Station Identity Switcher, Side-by-Side Monitoring, and Recipient Inbox API Wiring

## Objective
Enable seamless operator identity toggling between Station Alpha (`endpoint-a`) and Station Bravo (`endpoint-b`), provide a dual-station side-by-side monitoring mode, and wire direct recipient inbox querying via `GET /api/v1/endpoints/<id>/inbox` to verify that incoming messages exist in recipient durable storage with visible persistence verification badges.

<must_haves>
- Station identity switcher in `MessagesView.tsx` with segmented pill toggles for Station Alpha (`endpoint-a`) and Station Bravo (`endpoint-b`) and an instant "Swap Stations (⇄)" button.
- Split-screen / dual-station side-by-side view mode toggle (`single` vs `split`), allowing simultaneous monitoring of Station Alpha and Station Bravo without state loss.
- Active recipient inbox querying via `api.getInbox(selectedRecipientId)` and `api.getInbox(activeSenderId)` reconciling against durable storage records in SQLite.
- "Inbox Persisted" / "Recipient Inbox Verified" indicator badge rendered on messages confirmed to exist in recipient durable inbox storage.
- Successful TypeScript compilation and production bundle build with `npm run build` in `frontend/`.
</must_haves>
