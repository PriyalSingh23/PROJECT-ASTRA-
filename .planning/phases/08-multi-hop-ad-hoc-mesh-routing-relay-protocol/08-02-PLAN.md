# Plan 08-02: React Three.js Stratified 3D LinkTopologyView, Neon Laser Vectors, Animated Particles, RelayInspectorDrawer & Tactical Test Bench Ribbon

## Objective
Upgrade the SHADOWCOMM frontend with an interactive React Three Fiber 3D tactical mesh visualization and test bench. This includes rendering a stratified 3D map with ground relays at $Y=0$ and aerial UAV flight corridors at $Y=+4.5$ and $Y=+6.0$ with continuous orbital drift; dual-layer mesh links (dormant zinc lines vs glowing neon cyan active forwarding vectors with animated photon pulses); floating HTML tactical HUD pills with battery, storage, and queue depth; a slide-over `RelayInspectorDrawer` for deep telemetry and manual state toggles; 4 quick-view camera presets; and an interactive `MeshTestBenchRibbon` featuring 3 one-click operational drill scenarios ("UAV-Alpha Signal Lost", "Ground Relays Jammed", "Convoy Mobile Breakout") achieving sub-300ms route re-convergence with red strikethrough broken links and pulsing amber diversion banners.

<threat_model>
### T-08-05: WebGL Context Exhaustion & UI Unresponsiveness during High-Frequency Animation
- **Threat:** Continuous `useFrame` animation loops for UAV orbital drift and particle pulses combined with rapid canvas re-mounting during tab switching causes WebGL context loss or dropped frames (< 20 FPS).
- **Impact:** Black canvas, unresponsive UI controls, or browser tab memory crash during critical operations.
- **Mitigation:**
  - Retain a single persistent `<Canvas>` instance with React `memo` and optimized Drei primitives.
  - Compute trigonometric orbital drift using clock delta with capped buffer arrays.
  - Use `Line` components from `@react-three/drei` with fixed point buffers rather than regenerating geometries every frame.
  - Provide graceful degradation via existing `TopologyFallback` if WebGL is unavailable.

### T-08-06: Operator Confusion during Rapid Route Re-Convergence
- **Threat:** During dynamic rerouting, the route abruptly shifts without visual feedback on what failed, leaving the operator disoriented regarding whether data was dropped.
- **Impact:** Operator re-sends messages unnecessarily or makes faulty tactical decisions.
- **Mitigation:**
  - Multi-tier visual cue: failed node turns pulsing red (`#f43f5e`); broken link renders as dashed red strikethrough for 4 seconds; new path illuminates in cyan.
  - High-visibility amber banner appears at top of screen: `[MESH REROUTE: Bypassed relay-uav-alpha -> Diverted via relay-ground-02 -> Delivered]`.
  - Convergence latency is explicitly clocked and displayed (e.g. `42ms Convergence`).
</threat_model>
