<threat_model>
### T-05-01: Model Checkpoint Tampering, Bit Rot, or Unverified Neural Inference
- **Threat:** Operators may be unaware that a checkpoint is compromised if the UI does not provide explicit, unmistakable cryptographic verification seals and fallback indicators.
- **Impact:** Misplaced operational trust in compromised neural weights.
- **Mitigation:**
  - Dedicated Governance Panel renders live SHA-256 seal with green `[MANIFEST VERIFIED: MATCH]` badge.
  - Manual "Re-Verify Checkpoint" button allows immediate validation against disk manifest.
  - Interactive "Simulate Digest Mismatch" button proves fallback behavior and surfaces warning states.

### T-05-02: Simulated Tamper Desynchronization & Silent Failure of Fallback
- **Threat:** If analytical fallback engages without clear visual indications, operators might believe live neural inference is active when synthetic data is being displayed.
- **Impact:** Misinterpretation of synthetic noise as trained LPI-CGAN modulation.
- **Mitigation:**
  - Subtle card footnote `(Analytical Fallback Active: Neural Inference Disabled)` renders on all signal charts and constellation scatter plots.
  - Status banner shifts from emerald to amber with clear rationale.

### T-05-03: Apple Silicon PyTorch MPS ComplexFloat Kernel Crash
- **Threat:** If the frontend assumes MPS acceleration is active across all operations without reflecting CPU fallback in telemetry, operators cannot diagnose performance bottlenecks.
- **Impact:** Confusing latency measurements and unexplained CPU utilization.
- **Mitigation:**
  - Status pill explicitly shows `[APPLE SILICON: MPS READY]` or `[CPU FALLBACK ACTIVE]`.
  - Comparative benchmark card visualizes real CPU vs MPS latency (ms/frame) with calculated speedup factors.

### T-05-04: Flowgraph Parameter Drift & Accidental Unauthorized Band Transmission
- **Threat:** An operator could attempt live over-the-air transmission without realizing the USRP carrier frequency or bandwidth settings.
- **Impact:** RF transmission in unauthorized bands.
- **Mitigation:**
  - Flowgraph diagram explicitly displays `2.484 GHz (ISM Ch 14)` and `245.76 kS/s`.
  - Amber `[SDR: STANDBY / DISCONNECTED]` pill locks out transmission controls when USRP is disconnected.
  - Physical keying requires two-step confirmation modal with an armed interlock switch.
</threat_model>
