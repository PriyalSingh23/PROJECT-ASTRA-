# Plan 01-02: Worker Auto-Launch and UI Verified Receipt Rendering

## Objective
Enable single-command execution of the messaging server and background worker via `--with-worker` in `messaging/server.py` and `scripts/dev.sh`, and update the React tactical console in `frontend/src/components/MessagesView.tsx` to render the green "ACK Verified" badge and cryptographic signed receipt for delivered messages.

<must_haves>
- `messaging/server.py` accepts `--with-worker` CLI flag and launches a background worker daemon thread.
- `scripts/dev.sh` supports clean single-command orchestration and graceful shutdown.
- `MessagesView.tsx` displays the green "ACK Verified" badge when `current_state === 'DELIVERED'`.
- `MessagesView.tsx` renders `signed_ack_receipt` in a monospace card in the message inspection panel.
- Frontend builds cleanly via `npm run build` without TypeScript errors.
</must_haves>

<tasks>
<task>
  <name>Task 1: Add --with-worker flag to messaging/server.py</name>
  <read_first>
    - Final-Project/messaging/server.py
    - Final-Project/messaging/worker.py
  </read_first>
  <action>
In `messaging/server.py`, add `--with-worker` (action="store_true") argument to `main()`. If `args.with_worker` is set:
1. Define a helper function `_start_embedded_worker(db_path: str)` that instantiates `QueueWorker(worker_id="embedded-worker", db_path=db_path, poll_interval=1.0)` and calls `worker.run_forever()`.
2. Start the helper function in a daemon thread:
   `worker_thread = threading.Thread(target=_start_embedded_worker, args=(args.db,), daemon=True, name="EmbeddedQueueWorker")`
   `worker_thread.start()`
3. Log `Embedded Delivery Worker daemon launched successfully`.
  </action>
  <acceptance_criteria>
    - `python3 -m messaging.server --help` output includes `--with-worker`.
    - `messaging/server.py` contains `daemon=True` thread starting `QueueWorker`.
  </acceptance_criteria>
  <verify>
    python3 -c "import subprocess; res = subprocess.run(['python3', '-m', 'messaging.server', '--help'], capture_output=True, text=True); assert '--with-worker' in res.stdout"
  </verify>
</task>

<task>
  <name>Task 2: Render ACK Verified badge and cryptographic receipt in MessagesView.tsx</name>
  <read_first>
    - Final-Project/frontend/src/components/MessagesView.tsx
    - Final-Project/frontend/src/types/index.ts
  </read_first>
  <action>
In `frontend/src/components/MessagesView.tsx`:
1. In the message details inspection sidebar, when a message is selected and `current_state === 'DELIVERED'`, render an "ACK Verified" badge in emerald/green with an icon (`ShieldCheck` or `CheckCheck`).
2. If `selectedMessage.signed_ack_receipt` is populated, render a "Cryptographic Receipt" section with a monospace container displaying the receipt string (e.g., `ACK-HMAC-...`).
3. In the message bubbles list, ensure delivered messages display the double checkmark icon in emerald green with tooltip "Delivered & ACK Verified".
4. Re-compile the frontend using `npm run build` to update `frontend/dist/`.
  </action>
  <acceptance_criteria>
    - `frontend/src/components/MessagesView.tsx` references `signed_ack_receipt`.
    - `frontend/src/components/MessagesView.tsx` contains `"ACK Verified"`.
    - `(cd frontend && npm run build)` succeeds with exit code 0.
  </acceptance_criteria>
  <verify>
    grep -n "signed_ack_receipt" frontend/src/components/MessagesView.tsx && (cd frontend && npm run build)
  </verify>
</task>
