# Plan 09-01: Backend Raw PCAP Wireshark Packet Generator, Diagnostics Export API & RF Link Budget Propagation Engine

## Objective
Implement backend tactical diagnostic tools:
1. Standard libpcap 2.4 binary generator (`messaging/pcap.py`) wrapping Envelope v3/v2 frames, Reed-Solomon codewords, and radio metadata in DLT_USER0 (LinkType 147) frames.
2. PCAP export endpoint (`/api/v1/diagnostics/pcap`) returning formatted `.pcap` byte streams compatible with Wireshark.
3. Tactical RF Link Budget propagation calculation service (`messaging/link_budget.py`) with `/api/v1/rf/link-budget` endpoint implementing Friis FSPL, two-ray ground reflection, antenna gains, and link margin ratings.
4. Comprehensive automated pytest suite (`tests/test_rf_field_tools.py`) verifying binary PCAP magic headers, frame lengths, and RF link budget math.

## Execution Steps

### Task 1: Create `messaging/pcap.py`
Implement standard libpcap 2.4 file header (24 bytes) and packet record headers (16 bytes):
- Magic: `0xa1b2c3d4` (microsecond resolution)
- Version: `2.4`
- Network: `147` (`DLT_USER0` for custom tactical radio protocols)
- Ring buffer: Store last 500 captured frame records.
- Functions: `generate_pcap_bytes(frames)`, `record_frame(frame_bytes, metadata)`.

### Task 2: Create `messaging/link_budget.py`
Implement RF Link Budget math:
- $\text{FSPL(dB)} = 20 \log_{10}(d_{\text{km}}) + 20 \log_{10}(f_{\text{MHz}}) + 32.44$
- Received Power: $P_{rx} = P_{tx} + G_{tx} + G_{rx} - \text{FSPL} - L_{\text{cable}}$
- Thermal noise floor: $N_0 = -174\text{ dBm/Hz} + 10 \log_{10}(B) + NF$ (approx $-114\text{ dBm}$ for 1 MHz BW, 6 dB NF)
- SNR & Link Margin: $\text{Margin} = P_{rx} - P_{\text{sensitivity}}$
- Presets: VHF (144 MHz, 47 dBm), UHF (433 MHz, 37 dBm), ISM (915 MHz, 30 dBm), L-Band (1.4 GHz, 33 dBm).

### Task 3: Expose REST APIs in `messaging/api.py`
- `GET /api/v1/diagnostics/pcap`: Streams binary PCAP file with attachment header `filename=astra_tactical_{station}_{timestamp}.pcap`.
- `POST /api/v1/rf/link-budget`: Accepts JSON params `{ distance_km, freq_mhz, tx_power_dbm, tx_gain_dbi, rx_gain_dbi }` and returns `{ fspl_db, rx_power_dbm, snr_db, link_margin_db, status }`.

### Task 4: Automated Verification Suite in `tests/test_rf_field_tools.py`
- Test PCAP header structure and packet timestamp offsets.
- Test Wireshark file validity (magic `0xa1b2c3d4`).
- Test RF link budget computations across all 4 tactical presets.
