# Plan 09-02: Frontend 60 FPS WebGL/Canvas Live Waterfall, Wireshark PCAP Export Button & 3D Topology RF Link Budget HUD

## Objective
Implement frontend components for Phase 9:
1. Export Wireshark (.pcap) button and download handler in `DiagnosticsView.tsx` with instant toast notification.
2. Floating glassmorphic Tactical RF Link Budget HUD (`LinkBudgetHUD.tsx`) mounted inside `LinkTopologyView.tsx` providing real-time Friis path loss and link margin ratings as nodes are viewed or routes change.
3. Enhanced Waterfall streaming integration in `AstraSpectrumWaterfallLab.tsx` with live API stream binding and export triggers.
4. Update `services/api.ts` and `types/index.ts` with PCAP download and link budget calculation endpoints.
5. End-to-end production TypeScript build and lint verification.

## Execution Steps

### Task 1: Update API Client & TypeScript Types
- Add `downloadPcapBlob()` in `frontend/src/services/api.ts`.
- Add `calculateLinkBudget()` in `frontend/src/services/api.ts`.
- Add `LinkBudgetRequest` and `LinkBudgetResult` in `frontend/src/types/index.ts`.

### Task 2: Implement `LinkBudgetHUD.tsx` in `components/topology/`
- Semi-transparent HUD overlay on 3D canvas.
- Band preset selector: VHF (144 MHz), UHF (433 MHz), ISM (915 MHz), L-Band (1.4 GHz).
- Displays Path Loss (dB), Received Power ($P_{rx}$), and color-coded Link Margin badge (Optimal, Marginal, Fade Threat).
- Real-time updates when switching active relay paths.

### Task 3: Wire PCAP Download in `DiagnosticsView.tsx`
- Add "Export Wireshark (.pcap)" button in Diagnostics console toolbar with Download icon.
- Triggers browser blob download with automatic timestamped filename.
- Displays toast notification with file size and LinkType 147 confirmation.

### Task 4: Enhance `AstraSpectrumWaterfallLab.tsx`
- Ensure 60 FPS requestAnimationFrame loop continues smoothly with Inferno / Viridis colormaps.
- Connect direct capture trigger to download current waterfall segment as PCAP.

### Task 5: Production Build Verification
- Execute `npm run build` in `Final-Project/frontend`.
- Verify zero TypeScript compiler errors and sub-1s Vite asset packaging.
