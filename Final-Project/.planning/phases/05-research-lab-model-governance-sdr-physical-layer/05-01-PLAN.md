# Plan 05-01: Model Checkpoint Governance, SHA-256 Digest Validation, and MPS Acceleration Detection

## Objective
Enforce rigorous model governance by validating the SHA-256 digest of PyTorch checkpoints (`lpi_v4.best.pt`, `generator_lpi.pt`, `decoder_lpi.pt`) against `run/export_manifest.json` before loading, and verify automated detection of Apple Silicon Metal Performance Shaders (MPS) hardware acceleration with deterministic CPU fallback.

<must_haves>
- `SDRResearchService.audit_checkpoints()` computes SHA-256 digests of all checkpoints and confirms `manifest_verified: True` against `export_manifest.json`.
- `SDRResearchService.get_environment_metadata()` inspects macOS hardware, detects Apple Silicon architecture, checks `torch.backends.mps.is_available()`, and falls back safely to CPU.
- Automated tests in `tests/test_lpi_v4.py` verify that model checkpoints load correctly and checkpoint SHA-256 digests match export manifests.
</must_haves>
